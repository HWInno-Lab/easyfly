# easyfly_target_tracking

TrackTarget 在首次捕获目标时，以无人机到目标的水平朝向建立固定 odom 偏移，长度为 follow_distance。后续目标移动会等量平移跟随点；同一任务内重新捕获 SORT ID 时保留该偏移。若首次水平距离不超过 0.3 m，则使用无人机当前航向的后方作为偏移方向。

此前每帧按当前位置重新计算视线方向，可能把目标的横向移动抵消：V-09 中人物往返约 4 m，无人机后半程范围只有 0.0685 m。固定偏移修正这种停留行为，原 1 m 航点重发门限仍保留，静止目标不连续触发微小航点。

航点显式传入 NaN 偏航，按 GoToWaypoint 契约保持当前航向，避免消息默认的 0 rad 把斜视目标转出相机。高度仍为目标高度加 follow_height，并限制在 0.8 m 至配置上限内。目标跳变、速度、新鲜度、任务半径、类别锁定、丢失悬停及子航点取消与终态确认规则不变。固定偏移不是绕障规划，不保证遮挡下的目标可见性；飞行仍经过 flight_control 安全链。
