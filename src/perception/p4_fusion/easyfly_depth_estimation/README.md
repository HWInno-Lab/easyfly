# EasyFly 独立双目深度估计

已完成软件与限定米制双目仿真验收。输入是独立、已校正的左右相机图像和对应每帧 CameraInfo；
通过 OpenCV StereoSGBM 实际计算图像视差，以 `Z = fx × baseline / disparity` 得到左相机
光学 Z 轴米制深度。此包不读取已有相机深度、激光深度或任何仿真深度真值。

左右图像及内参必须同源时间戳，光学帧固定且左右不同，P 投影有相同 fx/fy/cx/cy，左
P[3] 为 0、右 P[3] 为 -fx×基线。基线 0.02–1 m；图像必须已做水平极线校正，输入
CameraInfo 使用单位 R、零残余 D、校正后的 K/P；拒绝未校正原始镜头参数、裁剪和变焦
混用。现有单目 RGB-D 仿真机型不能提供这对独立双目输入，需显式配置双目相机源。

`/depth_estimation/depth` 为 32FC1 米，`disparity` 为像素，`variance` 为平方米；
无效区域为 NaN，不填洞、不从邻域或上一帧复制深度。左右一致性、局部纹理、唯一性、
斑点和量化相对不确定度门限共同过滤。方差仅表示 0.5 像素视差误差的敏感度，不包含
标定误差或完整统计置信区间。`camera_info` 保留左相机原始标定与源 header。

每输入最多 3 帧，160×96 至 1280×720，两线程匹配，0.5 秒源／接收和时钟进展门限。
断流、重复／错配时戳、时钟冻结、来源重复／替换和标定变化都不能延长旧深度有效性；
来源或标定代次改变会换会话。`status` 给出会话、源时间、有效比例、基线、标定哈希和
原因。下游必须按原始源时间及状态判断；本包不直接改写导航占据图或飞行目标。

```bash
ros2 run easyfly_depth_estimation stereo_depth --config /absolute/stereo.json
```

配置模板见 `config/stereo.example.json`。算法依据 OpenCV 4.5.4 官方 StereoSGBM 和
calib3d 文档： https://docs.opencv.org/4.5.4/d2/d85/classcv_1_1StereoSGBM.html 。

验收覆盖独立 Gazebo 左右相机、0.2 m 基线、2/4/8 m 纹理平面；原生深度真值只送给
独立见证者，不进入估计器。三档 P95 绝对误差为 0.00594/0.06378/0.18992 m，所测
中心区域有效覆盖率为 100%/100%/92.44%。边缘／遮挡区域继续保留 NaN，不把中心覆盖率
当作全帧覆盖率。空白纹理、左右遮挡、错配／负基线／未校正镜头、重复／替换源、冻结
时钟和回退检查通过；两种安装均运行了真实节点，正常退出。第一次纹理材质脚本错误
导致实际图像无纹理，节点正确输出全无效；该失败记录保留。

精度范围仅限上述纹理平面和已测分辨率，不能外推任意反光、弱纹理、动态不同步画面或
真实设备。硬件标定／同步及原有 RGB-D 机型的双目硬件输入仍需设备验收。
证据见工作区 `artifacts/stages1-3-20261028/depth-signoff.json`。
