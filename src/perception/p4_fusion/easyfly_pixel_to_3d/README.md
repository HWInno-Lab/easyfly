# easyfly_pixel_to_3d

## ALG-6 算法边界

中位深度及针孔反投影已迁入 easyfly_projection，普通视图借用深度字节。节点保留编码/端序、图像配对、TF、消息/frame contract 和可视化。原有 latest TF 回退仍保留；不将其描述为雷达相机两源精确时间契约。布局/非有限框显式拒绝。

V-09 的真实移动人物场景暴露了整框深度中位数被背景污染的问题。节点现使用检测框中心区域（宽、高各为原框的一半）的中位深度，仍沿原框中心像素反投影。深度范围及有效比例门限不变；中心区域有效像素不足则发布无效位置，不回退到外围背景。该方法不能保证框中心被遮挡或落在背景时仍正确。

回归样本保留在 easyfly_projection/test/data：原始仿真深度 ROI 的整框中位数为 3.66460061 m，中心区域为 2.58589625 m；测试同时验证缺少中心深度时拒绝输出有效位置。
