# EasyFly Web 任务工作台

提供离线前端、原生状态观察和既有受管任务服务接入。浏览器通过 HTTPS 连接
`web_server`；页面没有外部字体/CDN/脚本依赖，不直连 DDS，也不发送任意飞控命令。
默认只读，管理员同时开启 `enable_execution` 并配置 `operator` 个人账户后，
才可执行白名单中的任务。底层继续使用现有 FSM、SDK、动作所有权和飞行准入逻辑。

## 启动

复制 `config/server.example.json` 为本人私有的 0600 文件，配置平台 UUID、实际
ROS domain 和时钟、个人账户、明确任务白名单、私有状态目录、有效 HTTPS 证书/私钥。
每个 token 文件为本人私有、32–128 位 URL 安全字符，使用密码学随机源生成，
不同个人账户不可共用 token。证书必须覆盖 `origin` 主机名，并由浏览器信任的 CA 签发。

```bash
ros2 run easyfly_web web_server --config /absolute/private/web.json
```

访问配置中的 `origin`，输入个人 token。令牌只在页面内存中保存；本页面会话 ID 和
原请求 ID 存于 sessionStorage，重载后重新登录即可查询。浏览器丢失这些 ID 时应通过
原平台的运维查询处理，不能把新请求当成旧任务的恢复。

服务必须与唯一的原生 `easyfly_mission_srvs` 节点处于同一 ROS 域。使用
`/platform/mission/details` 与 `/platform/mission/reviewed`；不调用旧的无内容哈希
启动接口，不提供任意路径、目录写入或远程脚本执行。
`/uav_state`、`/flight_status` 分别检查源时间、接收时间、有效标志和唯一 DDS 发布者；
发布者改变时重建订阅，过期/冻结时钟/回退时清除显示，回退后需要新网关会话。
DDS 本身仍是受信的机器人内部网络；Web 账户认证不替代 DDS 网络隔离。

## 任务与权限

`viewer` 可看状态和审阅原文，不能启动或取消；`operator` 只能处理该个人账户与
页面拥有的请求。操作顺序是选择任务、读取原文、核对当前平台与任务、执行、查询。
审阅由原始内容 SHA-256、任务服务启动 ID 和 2 分钟期限绑定；文件变化会被原生
任务服务拒绝。平台 ID、网关启动 ID、原生请求 ID、执行 ID 各有用途，不能混用。

启动前先持久化请求及归属，再调用一次原生受管启动。HTTP/ROS 超时、页面退出和
网关重启不重发启动、不取消任务、不推断成功；查询只对原任务服务 ID 调用 lookup。
任务服务重启后旧执行无法确认，呈现未知并留存证据，不向新服务重放旧任务。
取消必须匹配已接纳的执行 ID，取消请求亦先持久化；收到取消响应不等于控制权释放。
取消提交后反复查询，直到原生服务确认为已结束且 `execution_pending=false`。

状态目录的 SQLite 最多保留 256 个启动意图，审阅内存最多 64 个，ROS 队列最多 8 项，
单次 ROS 等待 2 s。请求体最多 4 KiB、任务原文最多 64 KiB、HTTP 串行处理，
TLS 握手/不完整请求超时 1 s。达到容量后在无未决执行的维护窗口归档，不自动删证据。
关闭 Web 进程只释放本地观察器与监听端口，不负责终止远端任务。

服务拒绝跨源写请求、异常 Host、错误账户和未配置任务；前端使用固定静态资源、
CSP 和 textContent，不解释任务原文为 HTML。读取与操作权限在服务端执行。

## 验收

测试覆盖权限、内容确认、原请求防重复、未知结果、重启和取消归属；阶段验收运行
已安装 Web 服务、原生任务门面与原生 FSM，以地面等待任务验证完整读回/执行/取消。
浏览器验收检查真实按钮流程、只读账户、断线清除和桌面/移动布局。
这些软件验收不替代实机操纵、现场链路和阶段 4 的飞行验收。
