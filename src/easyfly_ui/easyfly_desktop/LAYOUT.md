# 工作区布局与使用

连接管理始终排在导航第一项，随后是运行总览、任务中心、相机与感知、空间视图、记录与回放、诊断与设置。

## 配置连接

顶部下拉框切换配置。“管理配置”集中新建、复制、改名、删除和导入导出；未保存编辑切换时仍需确认。管理窗口和主页面的保存动作一致，保存不会启动连接。

工作方式用一行按钮选择：本机仿真、连接 DDS、本机飞控。运行环境、算法配置、飞控链路、DDS、QGC、权限使用一层分类页签。只有当前分类内容纵向滚动；保存、启动、结束观测、停止后台固定在页面下方。

算法页同时显示启用/策略与图像输入，按需展开高级检测参数。仿真高级设置、场景预览、连接诊断也按需展开。运行中的生效配置继续冻结，算法保存后重启会话生效。

QGC 的程序选择、转发地址/端口、打开与关闭操作集中在 QGC 分类中。结束观测保留后台；停止后台仍是独立操作。

## 配置与执行任务

任务中心顶部持续显示任务目标及认证身份，提供“任务与执行”“任务编辑”两个页签。选择本机仿真／DDS 或当前机载平台时切换各自目录、保存与执行通道，保留原连接、草稿和请求身份。

“任务与执行”采用左侧任务目录、右侧步骤／详情的可调宽布局。仿真执行状态在右侧顶部，执行与查询详情放在右侧正文的页签中，已启用的启动／取消操作固定在右侧底部；机载目录与审阅执行也使用两栏，不增加第三个窄栏。

“任务编辑”默认同时显示左侧步骤与右侧参数，参数长表单独立滚动，应用/重置按钮位于主体底部。小窗口下编辑器整体纵向滚动，步骤／参数主体保持最小可用高度；“保存到平台…”保持在外侧固定操作区。几何示意和高级 YAML 为另外两个视图。任务文件名始终显示，导出与目录设置按需展开。机载读取的任务可作为原文副本进入同一编辑器；点击编辑页底部“保存到平台…”查看目标与当前版本并确认保存，保存后仍须重新读取审阅才可执行。本机仿真与机载保存均直接使用当前已校验且无未应用表单修改的版本，无需先导出本地文件；本地导出独立可选，平台保存与执行仍分别确认。保存窗口关闭后保留目标及请求状态，重开继续查看；任务中心不再单列“校验与导入”。

步骤与参数显示中文名称及英文键、单位、范围、功能和依赖，保留九类步骤的离线编辑。模板提供基础飞行、航点巡检、区域搜索、自主探索、精准降落和目标跟随，创建模板不执行任务。平台提示区分已适配、尚未适配、未就绪和能力未知，不能替代执行许可。编辑、校验与保存状态简明显示，哈希等技术信息按需展开。

保存成功后刷新目录，并显示“查看并审阅已保存任务”；此入口仅定位或读取平台版本，不启动任务，也不自动勾选执行审阅。

## 观察画面

相机页上方选择图像源和显示模式，左侧画面占主要空间，右侧显示图像、目标和障碍状态。“数据表”在全宽底部显示同帧图像结果、目标、障碍与算法接口。“专注观察”临时收起状态栏和数据表，“恢复面板”恢复原来的展开状态。

RViz 上方选择预设、打开或释放三维，右侧调整图层和视角；也可切换专注观察。打开页面不会自动启动 RViz。

总览标题只保留“运行总览”，不再设置三维入口。顶部展示当前观测、定位可用性、飞控连接、模式与解锁状态、局部原点以上 Z、水平／升降速度和电池；三维合速度及原始状态放入“详细状态”。飞控连接失效时解锁和模式标记为最后已知，异常摘要按实际状态显示。

姿态与局部航向以紧凑悬浮面板嵌入当前地图右下角，可收起／展开；小地图默认收起，手动选择跨地图保留。局部地图和地理地图切换时面板随之移动，地图放大时仍可观察。右侧单独留给相机，放大相机时地图与仪表一起隐藏，恢复后回到原布局。仪表仍使用局部 ENU 航向，不将其当作地图真北航向。

地图可选择自动、局部或地理显示。自动模式依据原始 GPS 有效性选择，短时丢失保留失效提示后回到局部显示；支持手动切换。地理视图可直接选择街道地图或离线底图，基准等详细设置收进地图设置。实际全球轨迹按源时间采样；局部任务叠加到地理地图须有明确同坐标系基准。

总览局部地图默认显示“障碍栅格”，在“图层”菜单中可开关栅格或叠加“实时障碍框”。栅格来自当前 odom 占据数据，空白表示未标占据，不代表已探索或可以通行；栅格失效后清空并显示原因。静态障碍框仅平滑相邻有效观测的小幅边界变化，新增、消失、大幅变化或动态障碍立即显示实际观测。

空间视图的“局部二维”采用相同的默认障碍栅格和可选实时障碍框，在标题右侧的“图层”菜单切换；两处图层选择各自独立，共用同一份原始观测与显示规则。

局部地图自动视野可随新几何向外扩展，不随感知图层的短暂过期立即缩小；过期目标与障碍仍按原规则隐藏。“适应任务”、新观测会话或时间域重置会重新计算视野；手动缩放与拖动不变。

任务摘要和地图使用状态机实际发布的执行上下文，绑定原文字节哈希、目标 UUID 和步骤；草稿或目录选择不影响运行任务图层。已完成、当前和待执行任务点有不同标记，动态探索目标还须匹配该任务的实时反馈。没有可关联的任务信息时说明等待数据，过期进度标历史。

右侧相机支持直接切换前视／下视，和相机页共享所选源。地图与相机均可放大并恢复原分栏；三维内容统一在“空间视图”。详细状态和会话事件按需展开。

同一相机短时缺帧时，最多保留最近成功图像五秒，并用琥珀色“画面暂停 · 已过期”标注；不作为新鲜帧或录像输入，也不保留旧感知叠加。新帧恢复后解除暂停；切源、换会话、时间域重置、数据无效、断连或超过历史期限时清空。

## 尺寸与偏好

适配 1440×900、1366×768 和最小 1024×720。保持正文可读字号，配置表单不使用水平滚动。相机结果表、总览、RViz、任务编辑和任务执行的分栏支持拖动，用户拖动后的比例保存在本机 EasyFly 桌面偏好中；临时切换专注模式不会覆盖它。

前视相机的同帧检测、跟踪、椭圆和彩线模式保留最近完成的“图像与同帧结果”组合；新结果与原图到达不同步或尚在转换时，待新组合完成后整体替换。检测／跟踪仍按原一秒、椭圆／彩线按原半秒期限检查；过期只显示最长五秒且带暂停标记的同源图像，并清空叠层、表格与当前时间戳。有效空结果正常替换，切换来源／模式、时间域变化或明确无效数据立即清空。总览和录像继续独立使用原图。

仅当桥接验证同 header、尺寸和时间域的先前有效结果原样到期时，按过期通知保留暂停像素并立即清除叠层；其他无效数据继续清空，重复通知不延长历史画面的期限。

相机图像输入自动匹配发布者可靠性；可靠发布者采用可靠接收，尽力而为发布者仍可接入。桥接工作线程保存仍在原始有效期内的完整同帧组合，避免新但尚未完整的数据覆盖已配对结果。换源、时间域重置、图像冲突和明确无效数据仍清理相关缓存。
