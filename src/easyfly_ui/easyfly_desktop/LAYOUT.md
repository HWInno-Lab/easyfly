# 工作区布局与使用

连接与仿真始终排在导航第一项，随后是运行总览、任务中心、相机与感知、空间视图、记录与回放、诊断与设置。

## 配置连接

顶部下拉框切换配置。“管理配置”集中新建、复制、改名、删除和导入导出；未保存编辑切换时仍需确认。管理窗口和主页面的保存动作一致，保存不会启动连接。

工作方式用一行按钮选择：本机仿真、连接 DDS、本机飞控。运行环境、算法配置、飞控链路、DDS、QGC、权限使用一层分类页签。只有当前分类内容纵向滚动；保存、启动、结束观测、停止后台固定在页面下方。

算法页同时显示启用/策略与图像输入，按需展开高级检测参数。仿真高级设置、场景预览、连接诊断也按需展开。运行中的生效配置继续冻结，算法保存后重启会话生效。

QGC 的程序选择、转发地址/端口、打开与关闭操作集中在 QGC 分类中。结束观测保留后台；停止后台仍是独立操作。

## 配置与执行任务

“任务与执行”集中目录、校验、步骤、算法依赖。“执行与查询”在当前页右侧展开，启用任务控制时默认显示；只读查询时按需打开。

“任务编辑”默认同时显示左侧步骤与右侧参数，参数长表单独立滚动，应用/重置按钮固定。几何示意和高级 YAML 为另外两个视图。导出与目录设置按需展开，编辑、导入、执行仍分别确认。

## 观察画面

相机页上方选择图像源和显示模式，左侧画面占主要空间，右侧显示图像、目标和障碍状态。“数据表”在全宽底部显示同帧图像结果、目标、障碍与算法接口。“专注观察”临时收起状态栏和数据表，“恢复面板”恢复原来的展开状态。

RViz 上方选择预设、打开或释放三维，右侧调整图层和视角；也可切换专注观察。打开页面不会自动启动 RViz。

总览保留紧凑状态指标，将主要面积分给地图、姿态与相机。事件、观测证据、详细说明按需展开。

## 尺寸与偏好

适配 1440×900、1366×768 和最小 1024×720。保持正文可读字号，配置表单不使用水平滚动。相机结果表、总览、RViz、任务编辑和任务执行的分栏支持拖动，用户拖动后的比例保存在本机 EasyFly 桌面偏好中；临时切换专注模式不会覆盖它。
