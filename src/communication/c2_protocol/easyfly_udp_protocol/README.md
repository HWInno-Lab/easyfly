# 独立 UDP 协议与里程计传输

本包与 MAVROS UDP 独立。`udp_peer` 在两个显式 IPv4 端点间传递原生 `nav_msgs/Odometry` 和带随机挑战的心跳，完整保留源时间、两个坐标系、位姿、速度以及两组 6×6 协方差。输出话题不会发布 TF 或执行飞行动作。

```bash
ros2 run easyfly_udp_protocol udp_keygen /absolute/new-private-directory
ros2 run easyfly_udp_protocol udp_peer --ros-args --params-file /absolute/peer.yaml
```

每端各自生成密钥；将对端的 `public.key` 路径填入配置，私钥保留在本端 0600 文件中。新建目录不得已存在。使用系统 `cryptography` 的 [Ed25519 签名与验证接口](https://cryptography.io/en/3.4.8/hazmat/primitives/asymmetric/ed25519.html)，没有自制密码算法。节点 ID 是完整公钥 SHA-256 的前 128 位；每包仍用完整已固定公钥验签。私钥、令牌不进入日志。

线协议 v1：网络字节序头 `!4sBBH16s16s16sQQHH`，依次为 EFLY 魔数、版本、类型、保留零标志、来源／目标／会话 16 字节 ID、序号、UTC 纳秒签发时间、TTL 毫秒和载荷长度；末尾 64 字节签名覆盖上下文 `EasyFly/UDP/v1\0`、整个头及载荷。单报文最多 1200 字节，不做分片重组。类型 1 为里程计，2/3 为 8 字节挑战 Ping/Pong，4/5 留给 Mesh 邻接与链路传播。点对点节点拒绝 4/5。里程计载荷为 `!Q85d`（源纳秒与 85 个 double），随后各一字节长度加父／子坐标系 ASCII，完整长度严格检查。

只接收已配置源地址／端口、签名公钥和目标 ID；同会话拒绝重复／乱序，旧会话退休后不能重新进入。每个来源最多保留 64 个退休会话，达到后要求停机维护并重启接收端。每个接收进程的重放窗口保存在内存，不宣称跨接收端重启的持久恰好一次投递。原始观测仍受自身时间门限检查。

默认 TTL 1.5 秒，最多 5 秒，允许发送主机领先本机 250 ms；两端主机 UTC 需要同步。ROS 源龄默认 1 秒，两端须采用同一 ROS 时钟语义。单调时钟检查心跳和收件过期；仿真时钟冻结后停止有效里程计输出，回退锁存至节点重启。节点重启产生新会话；同会话内的坐标系变化被拒绝。

默认最大原始发送速率 20 Hz、签名校验输入预算 100 报文／秒、内核接收缓冲 256 KiB、待发布数据至多一条。UDP 可丢包，采用最新有效观测，不承诺可靠消息投递。`~/status` 分别报告近期收件、往返挑战是否新鲜、实测 RTT、里程计有效性及异常／限流计数。载荷经签名认证但未加密，不用于承载秘密；跨机机密数据应运行在已加密网络内。
