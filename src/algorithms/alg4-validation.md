## 1. 实际结构

| 部分 | 当前归属 | 保留职责 |
| --- | --- | --- |
| 匀速预测/历史模型 | `tracking/easyfly_motion_prediction` | 普通观测/结果类型、双时钟有效性、速度/跳变、预测和方差模型 |
| 点云过滤 | `preprocessing/easyfly_pointcloud_filters` | 球域距离、体素 first-wins、完整 XYZ/intensity |
| 预测节点 | 原 easyfly_target_prediction | 消息转换、时钟采样、互斥调度、定时发布和能力服务 |
| 点云节点 | 原 easyfly_pointcloud_filter | Livox 解析、源时间 TF、等待队列/水位/过期、PointCloud2 封装 |

两个实现包仅依赖 C++17 标准库，导出 namespaced INTERFACE target，不引入 ROS、PCL、
Eigen 或 TF。现有普通类型和函数已经满足本批调用需要，没有新增空接口包或工厂。
两个旧头仅包含新头及 using 别名，没有第二份计算实现。节点通过 target 声明依赖。

## 2. 等价与边界

保留原始两个头，分别编译原版和迁移版对照程序。320 步混合预测状态及 60 组点云，
10,819,070 字节输出完全相同，SHA-256 为
`9757ed1b34f3cdfeda307e14f27a339b83527d41bb73028a6168dbc12eca53ef`。
预测比较所有观测、状态、位置、速度、时间、方差、valid 和 reason 字段；
过滤将保留点按完整属性规范排序后比较，不把 unordered_map 的遍历次序当成稳定接口。

额外对照源码：还原命名空间、头保护宏和新增许可头后，两份核心正文与原版相同；
还原 include、using 和空行后，两个节点正文也与原版相同。
消息/时钟/TF/队列逻辑没有改写，配置和 launch 文件保持原样。

预测保留两次有序真实观测、空帧/ID 消失、类别变化、三维范数限速和跳变规则。
参考时间、接收时间和时钟进度 watchdog 保持各自时钟域，暂停/回退与过期仍清历史。
predict 不创造或刷新真实观测，variance 仍为简化模型；没有新增预测到导航/飞控的连接。

过滤保持含端点的范围 0.3..25m、默认 0.1m 体素、首点及其全部属性；在源系过滤后，
再按原测量时间 TF 变换到 odom。十帧队列、1 秒 steady 等待上限、1 秒源年龄、
0.2 秒未来容差、时间水位及回退规则保持；不回退 latest TF。
原数值输入域和网格键打包方式沿用，不在本批扩大为任意 NaN/极端体素配置的支持。

## 4. 复验与范围

在本工作区加载 ROS、主安装与 scene-s3 兼容 underlay，在独立 prefix 构建上述四包后运行：

```bash
python3 tools/algorithms/verify_prediction_filter_install.py \
  --symlink-prefix artifacts/algorithms/alg4-20261018/initial/install \
  --output artifacts/algorithms/alg4-new-run
```

工具拒绝覆盖旧证据。构建显式使用现有 underlay，不等同于完整工作区 clean rebuild。
ROS 回归使用非零 DDS 域与合成消息，没有启动 PX4/Gazebo、发送飞行任务或连接真实飞行器，
没有覆盖主安装或停止用户仿真。未据此认证实际传感器精度或后续仿真链。
ALG0-B02/B03 和既有 semantic 退出问题仍保持原记录，未修复或重报通过。
