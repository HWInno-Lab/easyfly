# easyfly_astar

项目维护的 C++17 二维八邻域 A*、起点脱困和半格采样视线剪枝，迁自全局规划包。
依赖 `easyfly_grid_planner_api` 的普通类型和 SearchControl，无 ROS 运行依赖。
导出 target：`easyfly_astar::easyfly_astar`，公开头：`easyfly_astar/astar.hpp`。

默认沿用 >=50 占据、-1 未知可通行、5 格脱困、原邻域顺序/代价/剪枝与真实起终点。
脱困会保留真实起点；没有因此认证从占据起点到脱困格的通道。剪枝仍为原半格采样，
未增强为连续几何碰撞证明，也没有新增动态重规划。

`planPath(..., unstick_cells, control)` 支持 atomic 取消、steady-clock deadline 和展开上限。
展开数计入每个首次弹出的未关闭格（包括目标）；限额 0 禁止展开，恰好够用的限额可成功。
取消优先于 deadline，deadline 优先于展开上限；展开预算仅在展开前检查，
回溯/剪枝继续响应取消与 deadline。失败时 waypoints 为空，不返回可执行部分路径。

检查点覆盖脱困、open 队列弹出、展开、回溯、反转和剪枝/LOS 采样；这是协作式中断，
标准库分配/初始化、容器单次操作和调度不提供硬实时上界。
非法布局/非有限坐标明确拒绝；地图上边缘按半开边界处理，非法占据字节视为障碍。
调用方负责地图资源额度、参考系/时效接纳与执行准入。节点适配器默认限 4,000,000 格。
